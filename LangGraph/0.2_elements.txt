State :- 

-> The state is a shared data structure that holds the current information or context of entire application
-> In simple terms it is like the application memory keeping track of variable and data that nodes can access and modify as they execute 

Analogy 
Participants(nodes) write and read information on the whiteboard(state) to stay updated and coordinate actions 

-------------------------------------------------------------------------------------------------------------------------------------

Nodes :-

-> Nodes are individual functions or operations that perform specific tasks within the graph 
-> Each node receives input (often the current state), process it and produce an output or an updated state 

-----------------------------------------------------------------------------------------------------------------------------------------

Graph :-  
-> A graph in langgraph is the overarching structure that maps out how different tasks(nodes) are connected and executed
-> It visually represents the workflow, showing the sequence and conditional paths between various operations

Analogy 
A road map displaying the different routes connecting cities, with intersections offering choices on which path to take next 
----------------------------------------------------------------------------------------------------------------------------------------

Edges :- 

-> Edges are the connections between nodes that determines the flow of execution 
-> They tell us which node should be executed next after the current one completes its task 

Analogy 
Each track(edges) connects the stations(nodes) together in a specific direction
---------------------------------------------------------------------------------------------------------------------------------------------

Conditional Edges :-

-> Conditional edges are specialized connections that decide the next node to execute based on specific conditions or logic applied to current state 

Analogy 
In traffic lights colors (Conditional Edges) decide either to stop , slow , go (Nodes/Tasks)
--------------------------------------------------------------------------------------------------------------------------------------------------

Start :=

-> The start node is virtual entry point in langgraph marking where the workflow beings 
-------------------------------------------------------------------------------------------------------------------------------------------------

End :- 

-> The end node signifies the conclusion of the workflow in langgraph , Indication all intended processes are done 
-------------------------------------------------------------------------------------------------------------------------------------------------

Tools :- 

-> Tools are specialized functions or utilites that nodes can utilize to perform specific tasks such as fetching data from an api 
-> They enhance the capabilites of nodes by providing additional functionalities 
-> Nodes are part of graph structure while tools are functionalities used within nodes 
------------------------------------------------------------------------------------------------------------------------------------------------------------

ToolNode :-

-> A tool node is just a specific kind of node whose main job is to run a tool
-> It connects the tools output back into the state , so other nodes can use that information
-------------------------------------------------------------------------------------------------------------------------------------------------------

StateGraph :- 

-> A StateGraph is a class in langgraph used to build and compile the graph structure
-> It manages the nodes, edges, and the overall state, ensuring that the workflow operates in a unifies way and that data flows correctly between components
-------------------------------------------------------------------------------------------------------------------------------------------------------------------

Runnable :- 

-> A runnable in langgraph is a standarized executable component that performs a specific task within an ai workflow 
-> It serves as a fundamental building block, allowing for us to create modular systems 
---------------------------------------------------------------------------------------------------------------------------------------------------------------------

Messages :- 

Human Message :- represents input from a user 
System Message :- Used to provide instructions or context to the model 
Function Message :- represents the result of a function call 
Ai Message :- represents respones generated by ai models 
Tool Message :- Similar to function Message , but specific to tool usage 
-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------
